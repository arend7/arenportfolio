# Aren D'Souza | Portfolio

Static site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
Repo **Settings > Pages > Deploy from a branch > main / (root)**. The site is served from `index.html`.

## Intro
The **Intro** button (top right) blanks the page and a swarm of cursors rebuilds it. The first screen takes about 7 seconds, then the page auto-scrolls. Use the dock at the bottom for speed (-2x to 3x), music pause and **End**. `Esc` also ends it.

Music: add your own copy of the track as `assets/audio/alex-guesta-my-addiction.mp3`.

Code: `assets/js/intro.js`, `assets/css/intro.css`. Visual layer: `assets/css/polish.css`.
